# 📚 Library Management System

A **Spring Boot based Library Management System** designed to manage core library operations such as book management, user management, and book issue/return workflows.  
This project follows **clean architecture**, **RESTful APIs**, and **industry-standard backend practices**.

---

## 🚀 Features

- 📖 Add, update, delete, and view books
- 👤 Manage library users
- 🔁 Issue and return books with validations
- ⏳ Fine calculation for late returns
- 🔐 Admin authentication (role-based access)
- 📑 Clean REST APIs with proper responses

---

## 🛠 Tech Stack

- **Java**
- **Spring Boot**
- **Spring Data JPA**
- **Maven**
- **REST APIs**
